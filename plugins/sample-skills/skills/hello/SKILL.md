# Hello (sample skill)

Greet the user warmly, then tell them:

> sample-skills `hello` skill — **revision 1**

Bump the revision number above whenever you edit this skill and push. After an
auto-update, running `/sample-skills:hello` should show the new revision, which
confirms the update reached the machine.
